# Milestone 2 Measurement Data and Graphs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Normalize real OSM measurement data, render interactive Magnitude/Phase/Coherence graphs, and support manual fixture recording and replay.

**Architecture:** Extend the existing OSM boundary to emit complete normalized frames, then keep normalization/resampling and fixture serialization in focused TypeScript modules. React consumes a small measurement store and renders three reusable SVG plots; live and replayed data use the same ingestion path.

**Tech Stack:** Tauri 2, Rust, React 19, TypeScript, Zustand, Vitest, Testing Library, SVG

---
