# Milestones 0 and 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Windows Tauri desktop foundation and a diagnostics-only client for Open Sound Meter's verified Remote API.

**Architecture:** React renders diagnostics and talks through a TypeScript `MeasurementProvider`. Tauri commands delegate network work to a Rust OSM service because the verified API uses multicast UDP, framed TCP, and Qt-compressed responses rather than browser-compatible HTTP or WebSocket.

**Tech Stack:** Tauri 2, Rust, React, TypeScript, Vite, Zustand, Vitest, ESLint, Prettier.
